# Komunālis

Komunālis ir Android lietotnes projekts kopīgu mājsaimniecības izdevumu uzskaitei. Lietotājs varēs pievienot izdevumu, norādīt maksātāju un dalībniekus, apskatīt vienādu summas sadalījumu, bilanci un izdevumu vēsturi.

## Pašreizējais stāvoklis

- Ir sagatavots un publicēts interaktīvs K2 prototips.
- Android ieviešana tiks sākta pēc K4 sprinta plānošanas sapulces.
- Tehnoloģiju izvēle: Kotlin un Jetpack Compose.

## Prototips

[Atvērt Komunālis interaktīvo prototipu](https://komunalis-k2-prototype.asnate-veinberga.chatgpt.site/?v=4)

## K4 sprints

Sagatavotais sprinta mērķis, backlog vienības un akcepta kritēriji atrodas failā [docs/sprint-preparation.md](docs/sprint-preparation.md). Stundu novērtējumi un galīgais sprinta apjoms tiks apstiprināti plānošanas sapulcē.

## Darba process

- Stabilais atzars: `main`
- Funkcionalitātes atzari: `feature/<īss-nosaukums>`
- Labojumu atzari: `fix/<īss-nosaukums>`
- Izmaiņas tiek apvienotas ar pull request.
- Pull request drīkst apvienot tikai pēc akcepta kritēriju un pabeigtības definīcijas pārbaudes.
