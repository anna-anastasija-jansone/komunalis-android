## Izveidojamie uzdevumi

1. Android projekta pamats un navigācija
2. Izdevuma ievade un validācija
3. Maksātāja un dalībnieku izvēle
4. Vienāds sadalījums un apstiprinājums
5. Izdevuma saglabāšana un vēsture
6. Bilance un kvalitātes pārbaude

Katram uzdevumam jāizmanto repozitorijā sagatavotā backlog vienības veidne. Stundu novērtējumu un norīkoto izpildītāju pievieno plānošanas sapulcē.

## Sprinta beigu ekrānuzņēmums

Pirms pārskata sapulces atver visu dēli tā, lai vienlaikus redzami uzdevumu nosaukumi un to kolonnas. Ekrānuzņēmumā nedrīkst būt redzamas paroles, piekļuves atslēgas vai cita sensitīva informācija.
